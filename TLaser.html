7D Real-Time Neural Net Surrogate

TLaser replaces traditional slow numerical solvers with a 7D Physics-Informed Neural Network (PINN) surrogate model. By natively parameterizing the physical geometry, the twin instantly estimates distributions without mesh latencies.

The surrogate network maps a 7-dimensional input vector representable as: $$\mathbf{X} = [R_1, R_2, L, T_0, I_{\text{active}}, w_{\text{active}}, d_{\text{active}}]$$ to a 105-dimensional output vector, consisting of output power ($P_{\text{opt}}$),電光转换效率 ($WPE$), total terminal current ($I_{\text{total}}$), and 51-point longitudinal carrier density $N(z)$ and optical power $P(z)$ arrays.

Performance Acceleration: Prediction latency drops from seconds to < 5 milliseconds with an $R^2$ accuracy above 0.997 compared to the high-fidelity simulator.

Carrier & Photon Propagation Penalties

To enforce physical reality, TLaser integrates physical governing differential equations directly into the backpropagation pathway during surrogate training. This ensures conservation laws are satisfied even near threshold limits.

  • Carrier Continuity Residual: penalizes deviations from the steady-state rate equations: $$G_{\text{inj}} - R_{\text{rec}}(N(z)) - R_{\text{stim}}(N(z), P_{\text{tot}}(z)) = 0$$
  • Photon Propagation Residual: enforces the second-order wave intensity propagation along the cavity length: $$\frac{d^2P}{dz^2} - (\Gamma g(z) - \alpha_i)^2 P(z) = 0$$
Differentiable Loss: Integrating these constraints prevents non-physical oscillations, yielding smooth longitudinal distributions that strictly follow optical gain boundaries.

Online Parameter Optimization Loop

Due to environmental changes and manufacturing tolerances, unmeasurable physical parameters drift. TLaser establishes an active calibration process by comparing the predicted L-I-V curves against real-time measured inputs.

The optimizer uses an L-BFGS-B minimizer to fit the following variables: $$\boldsymbol{\theta} = [\alpha_i, \Gamma, C_{\text{multiplier}}, R_{\text{series}}, R_{\text{shunt}}]$$

  • Optical Loss $\alpha_i$ & Confinement $\Gamma$: shapes the threshold current and differential slope efficiency.
  • Auger Multiplier $C$: dictates the non-radiative recombination temperature droop.
  • Series $R_s$ & Shunt $R_{\text{sh}}$: aligns the terminal voltage curves including current leakage paths.

Methodology & Physics

Physics-Informed Neural Network with dynamic geometry inputs.

TLaser integrates the high-fidelity semiconductor physics from the Lasers core into a real-time digital twin. During dataset sweeps, the local active area cross-section $A_{\text{act}} = w_{\text{active}} \times d_{\text{active}}$ is varied, which scales both carrier generation rates and stimulated optical transitions.

This allows the digital twin to accurately predict Spatial Hole Burning profiles and electro-optical efficiency metrics for any ridge size without needing custom grids or rebuilding simulator boundaries.

Installation & Execution Guide

Launch the TLaser digital twin locally.

1. Clone & Install Dependencies

git clone https://github.com/ZhenwenWan/TLaser.git
cd TLaser
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt

2. Launch the Streamlit Control App

python -m streamlit run app.py

Simulate parameter sweeps instantly and run parameter calibration on the interactive dashboard.
