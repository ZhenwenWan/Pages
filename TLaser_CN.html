第一层：真实光模块

光模块是通信光电产业链中最终交付客户的商品级硬件产品。它是可直接测量与测试的起点。

  • 标准化封装形式： 标准的 SFP/QSFP 模块，可热插拔地插入交换机和服务器中。
  • 可测性能数据： 可轻松在系统运行中测试总输出光强、端电压与发射光谱（L-I-V）曲线。
  • 核心痛点： 内部激光器芯片的微观物性常数或物理损伤无法在不破坏外壳的前提下直接观测。

第二层：模块解耦与内部组件

拆解光模块后，内部包含协同调控电、光、热信号的多个子系统组件。

  • 发射光组件 (TOSA)： 封装了激光器二极管芯片，并将其光束耦合至光纤输出通道。
  • 辅助控制单元： 微型激光器驱动芯片、背光探测器（PD）监测光路、以及热电制冷器（TEC）。
  • 参数关联： TLaser 利用模块级可测信号，逆向求解这些子系统内部由于老化或工艺偏差引起的物性常数飘移。

第三层：激光器芯片与谐振腔几何

进入 TOSA 组件内部，即为产生相干光的有源核心——半导体激光器芯片。

  • 有源层 (MQW)： 电流注入并产生受激辐射、光子放大的多量子阱波导结构。
  • 谐振腔 (Cavity)： 提供光反馈的反射镜镜面（FP 腔解理面或 DBR 光栅）。
  • 参数化结构： 谐振腔长度（L）、脊波导宽度（w）和有源层厚度（d）决定了阈值和增益大小。

第四层：PLaser 正向物理仿真器

PLaser 充当正向物理求解器的角色。它回答了：“给出特定的几何设计和电热参数，芯片内部产生怎样的物理场并表现出何种宏观性能？”

  • 载流子传输与复合： 计算电子空穴连续性控制方程，包含辐射与非辐射（Shockley-Read-Hall, Auger）损耗项。
  • 光子场传播： 基于二阶波动方程求解谐振腔纵向各点的光强分布与空间烧孔效应。
  • 电热力耦合： 考虑大电流注入下的自热效应与结温漂移，重现热翻转特性。

第五层：TLaser 数字孪生与逆向工程决策

TLaser 作为逆向校准引擎，回答了：“给出一组实测的 LIV 曲线，内部物理参数当前的真实值是多少？”

  • LIV 数据导入与验证： 读取实测输入数据，并通过严格的 JSON Schema 进行校验。
  • 快速校准激光器： 基于 L-BFGS-B 算法逆向标定难以直接测量的 Rs, Rth, alpha_i 等常数。
  • 工程决策闭环： 参数同步后的数字孪生体可在毫秒级时间内评估老化极限、支持设计改进并进行可靠性预测。

7D 实时神经网络代理模型

TLaser 采用 7D 物理信息神经网络代理模型取代传统的慢速数值网格积分方法。通过将物理几何结构参数化，数字孪生系统无需重建网格即可在毫秒级时间内做出准确预测。

该代理模型输入为 7 维设计向量： $$\mathbf{X} = [R_1, R_2, L, T_0, I_{\text{active}}, w_{\text{active}}, d_{\text{active}}]$$ 输出为 105 维标量与数组，包含输出光功率 ($P_{\text{opt}}$)、电光转换效率 ($WPE$)、总输入电流 ($I_{\text{total}}$) 以及 51 个纵向位置点的载流子浓度 $N(z)$ 和光功率 $P(z)$ 空间分布曲线。

计算提速： 求解延迟从传统的数秒下降到 < 5 毫秒，与原高精度数值模拟相比，$R^2$ 拟合相关度保持在 0.997 以上。

载流子与光子传播物理惩罚函数

为了使深度学习模型的预测符合物理真实规律，TLaser 在训练的损失反向传播通路中直接嵌入了物理微分控制方程。这使得模型在阈值点附近和强热效应下也能保持极高的物理保真度。

  • 载流子连续性方程约束： 惩罚载流子产生、复合与受激辐射三者在稳态下的偏离： $$G_{\text{inj}} - R_{\text{rec}}(N(z)) - R_{\text{stim}}(N(z), P_{\text{tot}}(z)) = 0$$
  • 光子传播微分方程约束： 约束光强沿谐振腔纵向传播的二阶波动微分特性： $$\frac{d^2P}{dz^2} - (\Gamma g(z) - \alpha_i)^2 P(z) = 0$$
微分正则化： 物理约束彻底消除传统拟合曲线在网格点上产生的非物理性毛刺与振荡，提供完全连续平滑的物理剖面。

在线拟合与参数标定优化环路

由于器件老化、工艺偏差和工作环境剧烈变化，激光器内部物理常数会随时间漂移。TLaser 通过在线读取外置 LIV (光强-电流-电压) 传感器测试曲线，反向求解器件的真实物理属性。

标定优化程序采用 L-BFGS-B 极小化算法迭代更新以下 5 个关键物性参数： $$\boldsymbol{\theta} = [\alpha_i, \Gamma, C_{\text{multiplier}}, R_{\text{series}}, R_{\text{shunt}}]$$

  • 内损耗 $\alpha_i$ 与局域限制因子 $\Gamma$： 修正激光器起振阈值与电光效率斜率。
  • 俄歇复合乘数 $C$： 标定器件在大电流下的非辐射热骤降特性。
  • 串联电阻 $R_s$ 与并联漏电电阻 $R_{\text{sh}}$： 极高精度拟合器件在电路层面的总电压和寄生电流特性。
标定程序拟合 LIV 测试数据前后的效果对比。

VCSEL 扩展演示 (VCSEL Extension Mode)

垂直腔面发射激光器（VCSEL）数字孪生流程的简化物理验证与演示。

TLaser 引入了专门的 VCSEL 扩展演示模式，用于验证垂直腔面发射激光器的数值仿真与在线标定。该模式与边发射通信激光器模型（DFB/FP）物理架构分离，单独建立了基于圆柱形径向坐标系的简化物理求解器。

主要包含以下 VCSEL 特有物理机理与控制变量：

  • 氧化孔径 (Aperture Diameter)： 调节氧化层孔径以控制横向光模约束及注入电流密度分布。
  • 径向电流拥挤效应 (Current Crowding)： 真实仿真电极注入电流在氧化孔边缘集聚的物理现象。
  • 径向空间烧孔效应 (Spatial Hole Burning)： 仿真强受激辐射在光场中心引起的载流子局部凹陷。
  • 自热效应与热翻转 (Thermal Rollover)： 标定分布式布拉格反射镜（DBR）损耗与结温上升引起的功率骤降。
限制说明 (Notice)： 当前 VCSEL 仿真采用简化物性常数率方程（Reduced Physics Mode），在没有得到真实晶圆级 LIV-Wavelength 实测数据对齐验证前，仅作为数字孪生流程展示。

科学建模与基本物理

引入参数化动态几何输入的 PINN 神经网络模型。

TLaser 将 Lasers 研究核心的高保真度半导体物理规律集成至实时数字孪生体中。在数据集生成与标定求解中，有源层横截面积 $A_{\text{act}} = w_{\text{active}} \times d_{\text{active}}$ 随脊波导几何变化而自适应缩放，进而动态影响局域载流子注入率与受激辐射跃迁。

这使得孪生体能实时、无网格重新编译地评估包含空间烧孔效应在内的半导体内部多物理特征。

安装与本地运行指南

在本地快速启动并配置 TLaser 数字孪生环境。

1. 克隆代码与依赖环境配置

git clone https://github.com/ZhenwenWan/TLaser.git
cd TLaser
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt

2. 启动 Streamlit 本地交互面板

python -m streamlit run app.py

在弹出的浏览器面板中实时调节滑块进行参数分析，或上传实时曲线执行在线物性常数拟合。
